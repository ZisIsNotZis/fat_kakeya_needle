# 有限递推运动：Keich 三角形 + 连续转场

**用途与层级**：这是给定正有理数 `ε` 后可在有限步骤内定义的一条**理论**连续半转运动，充分小 ε 时面积 `O(1/log(1/ε))`。它不声明当前 Python 优化器已执行此递推，也不保证任一实用预算下取得最小数值；有理数及代数/反三角函数的精确表示、位复杂度和输出点数量均须计入实现成本。允许临时角度回摆与远距运动。基础阶数证明及下界见 `docs/continuous-motion-bridge.md`。

## 第 n 层有理三角形

对充分小的 `0<ε<1`，取 `n=max(1,floor(log₂(1/ε)/4))`、`M=2^n`、`h=1/M`，等价地用整数比较选最大的 `n≥1` 使 `ε≤2^(−4n)`。于是 `ε≤h⁴<16ε`。对 `q=0,…,M−1`，令 `e_i(q)∈{0,1}` 是 q 的**恰好 n 位**二进制展开，`a_q=q/M`，`b_q=−(1/n) Σ_{i=1}^n (i−1)e_i(q)2^(−i)`，`c_q=a_q+6b_q−2h`，并取闭三角形

`T_q=conv{(0,c_q),(0,c_q−h),(1,c_q+a_q)}`，`G_n=∪_{q=0}^{M−1}T_q`。

这与 Keich 1999 原文印刷第 216 页的直线截距式、第 218 页三角形向左平移一单位后的顶点一致。原文 Claim 3.1 的证明**先处理平移前的三角形及放大集合，再用平移不变面积**，得到 `G_n⊂[0,1]×[−6,6]` 与 `|(G_n)_h|≤36/n`；不能把平移前的包含关系直接套到平移后。文献与 PDF SHA 见 `docs/continuous-motion-bridge.md`。

## 有限站点及连续姿态原语

每个块 `k=0,1,2,3` 取旋转 `kπ/4` 的 `G_n`。对块内 `j=0,…,M−1`，取 `q=j` 的三角形**上边** `y=c_q+a_qx`（x∈[0,1]）；其长度 `sqrt(1+a_q²)≥1`，故取中点 `p=(1/2,c_q+a_q/2)`，截取居中的单位线段 `p+[-1/2,1/2](1,a_q)/sqrt(1+a_q²)`，并整体旋转 `kπ/4`。站点方向是 `θ_{kM+j}=kπ/4+arctan(j/M)`。最后追加方向 `θ_{4M}=π` 的站点：从第四块 `q=M−1` 的**下边**取斜率 1 的单位线段（下边自 `(0,c_q−h)` 至 `(1,c_q+a_q)`），再旋转 `3π/4`。于是共有 `4M+1` 个有序站点，块间也连接，即使边界方向等同但中心不同。角差不超过 h，中心间距不超过 `D=14`。

按站点次序：在当前站中心原地转至下一站方向，再将两站中心差 `v=A uθ+B uθ⊥` 通过下述**五步转场**消去；也可先转场后在新站转角，只需保证转场使用当时角度。令 `R=max(28,h^(−2))`，若 B≠0 选 `σ=±1` 使 `α=arcsin(−B/(σR))` 指向角度区间 `[0,π]` 内部，`t=A−σR(1−cosα)`，执行：沿旧轴滑移 `σR`；绕当前中心转 α；沿新轴滑移 `−σR`；绕当前中心转 `−α`；沿旧轴滑移 t。若 B=0，直接沿轴滑移 A。中心位移严格等于 `σR(uθ−u(θ+α))+t uθ=v`，末角还原，因此各原语连续接合。起点选首站角度 0，终点为 π；不要求中心回到起点。

四份三角形集合的 h-邻域面积 ≤`144/n`，全部站点原地短转落在其 `2h` 邻域；邻域放大界 ≤36 倍，故这一部分面积 ≤`5184/n`。每次转场面积 `O_D(εR+D/R+ε(1+D))=O(h²)`，共有 `4M=O(1/h)` 次，合计 `O(h)`。因此该**明确有限递推**的连续运动面积 ≤`5184/n+O(h)=O(1/log(1/ε))`。数字 5184 是粗上界常数，不应拿来预测可计算 ε 的最好面积。

## 可实施性边界

三角形有 `2^n` 个，生成其有理顶点约需 `O(n2^n)` 次初等运算；运动有 `4·2^n+1=Θ(ε^(−1/4))` 个站点，远行尺度 `R=Θ(ε^(−1/2))`。以上是**有限有效指定**而非已经写好的轨迹生成程序：实际实现需选择代数数/反三角函数表示、舍入与可证面积评估，并与当前光滑枢转族做包含发现成本的同预算比较。由于转场存在临时回摆，此递推不属于 `pivot_slide.py` 的单调等角运动族。它证明“在无限计算资源的理论意义上有一族与阶数一致的曲线”，尚未证明“在给定预算下击败所有已知方法”。
