## 2. 数学证明链逐项核查

### 2.1 输入与三角函数

- 原始 JSON 数字经 `parse_float=Fraction` 精确表示打印的十进制数，不声称等同优化器内部二进制浮点数。
- 普通 pivot-slide 和 smooth 的参数布局均对应原模型；对照 `smooth_pivot.py:46–54`，确实是先裁剪 f 控制点，再在等角指标上插值。
- Machin 公式与 arctan 交错余项的方向正确。sin/cos 的 17/18 项末端相邻部分和分别夹住真值；cos 初始项在 x≈π/2 时不单调不构成问题，因为使用的是高阶尾部交错界，尾项已经递减。
- 对内部角，π 上下界乘 j/(2K) 均仍在 [0,π/2]；使用 sin 递增、cos 递减取端点，再以 D=10^12 向外舍入正确。两端单位向量精确处理。

### 2.2 闭合、旋转、滑移

设 `gamma_i=beta_i+(f_{i+1}-f_i)/2`。第 i 段以固定 P_i 枢转，结束中心是 `P_i-f_i*u_{i+1}/2`；更新 `P_{i+1}=P_i+gamma_i*u_{i+1}` 后，下一段起点中心恰等于旧中心加 `beta_i*u_{i+1}`。因此滑移外包和下一旋转之间没有漏掉运动。

初始横坐标选择 `P0.x=-Σ gamma_i*cos(theta_{i+1})`，使最后 P 的横坐标精确为零；末段方向垂直，所以末矩形中心横坐标也为零。此处说的是区间计算所包围的真实精确运动，不是要求经过舍入的区间端点代数抵消。

对任意角点，半径满足

`R = sqrt((t-f_i/2)^2+v^2) <= |t-f_i/2|+|v| <= 1+eps/2`。

角度区间宽 Δ 时，圆弧参数函数的二阶导数范数为 R。端点线性插值的向量误差可由一维 Dirichlet Green 核积分界成 `R*Δ²/8`。该范数上界同时控制每个坐标；故端点四角盒的凸包加 L∞ 垫层确实覆盖所有中间角点。每个时刻的矩形是四角点凸包，因此整矩形扫掠被覆盖。实现中 `box_points(..., pad)` 再求 hull 正好实现凸包与正方形垫层的 Minkowski 和。

固定方向轴向平移的扫掠等于起末矩形凸包。区间端点盒向外包住起末姿态，故滑移 hull 是安全外包，即使 beta 为负或为零也成立。

### 2.3 镜像接合与半转

第一部分的终末垂直矩形中心在 x=0，关于该轴反射后为同一矩形。将反射后的第一部分逆序连接，第二部分姿态角从 π/2 连续走向 π，故形成连续半转。宽度轴反射的符号可以利用矩形关于自身轴的对称性处理；不要求把一条反射轨迹误当成保持手性的刚体变换。此论证不依赖最终位置等于初始位置。

### 2.4 闭网格计数

对凸多边形与一条闭水平带的交，x 投影是区间。实现枚举带内顶点与穿越带边界的边交点，能取得 x 极值；列范围 `ceil(q*xmin)-1 ... floor(q*xmax)` 确实覆盖包括边/点接触在内的全部闭单元。逐行整数区间合并不会遗漏，也不会把空间上重叠的覆盖重复计数。网格边界面积为零，因此覆盖面积不超过 `N/q²`。

## 4. 严格证明：原 v1 外包存在不随 q 消失的面积开销

对于原 .005 候选的每个 CCW 外包凸多边形，求 q=2048 时**整个闭单元四个角都在同一个多边形内**的列区间，再对全部多边形及镜像合并。每个入选单元都严格包含于外包并集（允许贴边），因而其总面积给出**外包并集面积下界**。

对边 a→b，令 dx=b.x-a.x、dy=b.y-a.y。四角叉积的最小值乘 q 是

`A*i+B >= 0`,

其中

- `A=-dy*D`
- `B=dx*j*D+q*(dy*a.x-dx*a.y)+min(0,-dy*D)+min(0,dx*D)`。

解各边的不等式即得整数列区间，全部使用整数，不需要 Shapely 或浮点面积。

计数结果：

`1,587,216 / 2048² = 99201/262144 ≈ .3784217834472656`。

因此：原 v1 多边形外包面积至少 .37842178；任何完整覆盖该固定外包的网格证书，不论 q 增多大，都不可能低于此数。**这不是实际运动面积下界，更不是 f(eps) 下界。** 它严格反驳“只靠细化空间网格即可将该 v1 证书逼近 .356855”的归因。相对 .356855 的差值中至少约 .02157 已不能通过仅增 q 消除。

建议将原文“网格开销约7%”改为“当前外包证书较浮点估计高约7%，差值混合了角段凸包/弓高垫层与空间网格开销，不能仅归因于网格”。原文“½阶收敛”也未给定拟合模型；倍增 q 时差分近似减半通常对应 1/q 型网格项，不能直接称为 1/2 阶。

## 7. 追加：全体运动有限 ε 下界独立审查

审查对象：`direction_overlap_lower_bound.py` 与 `docs/finite-eps-lower-bound.md`；此节不将指定运动的上界错误推广成下界。

**结论：接受有限方向公式、解析极限及有理舍入实现；未发现系数或方向重复漏洞。**

- 选 θ_j=jπ/n、j=0,…,n−1，不重复 θ=π；任意连续半转通过角度提升与介值定理均包含这些方向。回摆不影响从各方向选取一个矩形。
- 每对完整矩形交叠至多 min(ε,ε²/|sinθ|)，因为两矩形分别包含于宽ε条带。占据函数 M 的二次积分是**有序**方向对之和；按方向指标差模n分组，每组n对。对角项nε只出现一次，故分母正是1+Σ(k=1…n−1)min(1,ε/sin(kπ/n))，没有缺少或多乘2。
- 固定ε>0时 g(θ)=min(1,ε/sinθ)，在0、π定义为1，连续；分母含自交项1后，正好是完整左Riemann和。积分为2arcsin ε+2ε log((1+sqrt(1−ε²))/ε)，解析L(ε)及liminf系数π/2正确。该系数不是已证明的最优常数。
- 代码的三角下端 l/D≤sinθ，使 εD/l≥ε/sinθ；再向上量化到D分母、截在1，得到的是交叠系数**上界**。分母增大使面积下界下降，保守方向正确。
- `trig_grid(n//2)` 第k项角度为kπ/n。偶数n的对称计数是两倍1…n/2−1，加一次正交项n/2；零方向自交项另加D。n=2时中间和为空，仍然正确。
