# 有界 Kakeya 集到连续粗针半转：对数阶桥接证明

**严格结论（阶数，不含最佳常数）**：`f(ε)` 定义为所有合格运动扫掠面积的**下确界**，不假设最小运动存在；“连续转过 180°”要求角度的连续提升从 0 达到 π，不能只要求相同的无向矩形起终外形。对于平面中可以自由平移、旋转，允许角度短暂回摆、中心可随 ε 远行的 1×ε 矩形针，`f(ε)=Θ(1/log(1/ε))`（ε→0）。这不证明角度单调、中心统一有界或项目当前枢转剖面族也达到此阶；有限三角形阶段给出的**理论有效**位姿递推另见 `docs/keich-explicit-motion.md`，它不是实用预算最优方法。

## 原始文献提供的前提

U. Keich, *On Lp Bounds for Kakeya Maximal Functions and the Minkowski Dimension in R²*, 1999, DOI `10.1112/S0024609398005372`，可访问原文 `https://authors.library.caltech.edu/records/js5yc-8gw95/files/KEIblms99.pdf`（此次核验 PDF SHA-256 `9b94f16437157cd5dca35b9bc98cca3190741573a5255cd0173a9d33976f5a0e`）。印刷第 215 页 **Lemma 1** 陈述：存在**一个紧致** Kakeya 集 `E`，包含平面每一方向的一条单位线段，且对所有足够小 δ 有 `|E_δ|≤C/log(1/δ)`，C 与 δ 无关。其证明在第 218–219 页用嵌套 G-set 得到统一尺度界。证明正文的 G-set 最初仅保证斜率 [0,1]；将该紧 G-set 旋转 `0,π/4,π/2,3π/4` 后有限并，便覆盖全部无向方向、保持紧致和有界，邻域面积界至多增四倍。这一步不可省略。

紧致性给出固定直径 D。给定 δ，在同一个全方向集合中取 `n=ceil(π/δ)`，按 `θ_j=jπ/n (j=0,…,n)` 各选一条单位线段 `L_j=p_j+[-1/2,1/2]u(θ_j)`。站点数 `n+1=O(1/δ)`，中心距离 ≤D；令 `S=∪L_j⊂E`，则 `|S_δ|≤C/log(1/δ)`。这里的存在性选取不保证有限精度坐标易算。

## 完整、连续的转场

从当前角度 θ 的中心到下一中心，写位移 `v=a uθ+b uθ⊥`，有 `|a|,|b|≤D`。取 `R≥max(1,2D)`、符号 `σ∈{−1,1}`、`α=arcsin(−b/(σR))`、`t=a−σR(1−cos α)`；当 `b≠0` 选 σ 使 `θ+α∈[0,π]`。依次沿当前针轴滑移 `σR`，**绕当时针的中心**转 α，沿新针轴滑移 `−σR`，绕当时中心转回 `−α`，最后沿旧针轴滑移 t。总位移正好是 `σR(uθ−u(θ+α))+t uθ=v`，最终角度仍为 θ；`b=0` 只需直接轴向滑移。该运动连续、允许短暂回摆，不要求中心始终在 E 附近。

长度 ℓ 的轴向滑移的扫掠面积是 `ε(1+|ℓ|)`；中心小转角的扫掠面积 ≤`C₀(ε+|α|)`。由于 `|α|≤2D/R`、`|t|≤D+D²/R`，每次转场增加的面积至多 `C_D[εR+D/R+ε(1+D)]`。取 `R=ε^(−1/2)`，单次为 `O_D(√ε)`。在每个站点原地把角度转到下一网格角度（间隔 ≤δ），矩形落在该站线段的 `δ+ε/2≤2δ` 邻域中；所有这些局部转动的并集位于 `S_{2δ}`，不能把面积逐段相加。极大 δ-分离点的 δ/2 圆盘互不相交且包含于 `S_δ`，3δ 圆盘覆盖 `S_{2δ}`，故 `|S_{2δ}|≤36|S_δ|`。取 `δ=ε^(1/4)`，至多 O(1/δ) 次转场贡献 `O(ε^(1/4))`，局部转动贡献 `O(1/log(1/δ))`；由此得到**连续运动上界** `f(ε)=O(1/log(1/ε))`。

## 下界及不能推出的结论

任何连续半转至少经过 `n=ceil(1/ε)` 个方向 `θ_j=jπ/n`，**只取 `0≤j<n`，不重复终点**；在这些时刻选 `1×ε` 矩形 `T_j`，它们都包含于扫掠集 B。两条不同方向无限条带的交面积至多 `ε²/|sin(θ_i−θ_j)|`，同方向对角项面积为 ε。因此 `Σ_{i,j}|T_i∩T_j|=O(log n)`，而 `Σ_j|T_j|=nε≈1`；Cauchy–Schwarz 给出 `|B|≥c/log(1/ε)`。证明直接用矩形，不会错误地声称无端帽矩形包含整根线段的欧氏 ε/2 邻域。上下界合成上述 Θ 阶数，但**最佳乘性常数仍未知**。

Keich 给出集合构造与邻域量级，本文补自由连续运动的定量连接；其第 n 阶有限三角形还可组成 `docs/keich-explicit-motion.md` 中的有效公式。仍不意味着 `pivot_slide.py` 的固定 K 或固定控制剖面递推达到此阶，更没有给定 CPU 预算的最优坐标算法。数值实验、粗网格有理证书与这个渐近定理属于不同证据层，见 `docs/findings.md`。
