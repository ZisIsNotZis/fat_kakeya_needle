# 有理数连续枢转证书（首版）

`rational_pivot_certificate.py` 对 **指定 JSON 文件中某一个 seed 所定义的连续运动** 输出严格面积上界，不证明最优性或任何渐近标度；浮点优化值仅作候选来源。证书包括源文件 SHA-256、网格密度 `q`、覆盖的闭网格单元数 `N`，其严格面积上界为 `N/q²`。输出 JSON 中的字符串分数是精确值。验证器重新解析源文件、重建运动与外包、重新计数，并对证书每个字段作相等比较：

```sh
python3 rational_pivot_certificate.py results/pivot_005_K16_night.json --seed 1 --q 128 --verify results/rational_pivot_005_K16_seed1_q128.json
python3 rational_pivot_certificate.py results/coarse_refine_0002_K256.json --seed 0 --q 128 --verify results/rational_pivot_0002_K256_seed0_q128.json
python3 -m unittest -v test_rational_pivot_certificate.py
```

## 证明范围与可复核的外包推导

1. `json.loads(parse_float=Fraction)` 将输入 JSON 的十进制数**按文本精确转为有理数**；整数参数也在计算前转为有理数。K256 的分段线性控制点在有理角度指标上精确插值，枢轴分数逐点裁剪至 [-1,1]，与原模型一致。输入字节散列使文件替换可检测。
2. Machin 恒等式 `π=16 atan(1/5)-4 atan(1/239)`（四倍角正切公式及象限判定）和 `atan(x)=Σ(-1)^k x^(2k+1)/(2k+1)` 给出两个有理端点：前者取 32 项、后者 12 项，下一项大小界定余项。每个内角 `jπ/(2K)` 获得有理区间；0 与 π/2 使用精确单位向量。sin/cos 在 [0,π/2] 上单调，用端点 Taylor 17/18 项交错界，并向外取整至 `10^-12` 网格。
3. 用区间有理运算重建 `P₀.x=-Σ[βᵢ+(fᵢ₊₁-fᵢ)/2] cos θᵢ₊₁`，因此末端中心 `x=0` 是**未取整的代数恒等式**。姿态角点位于枢轴加 `(t-fᵢ/2)u(θ)+v u⊥(θ)`，`t=±1/2, v=±ε/2`；各端点外向舍入生成角点区间盒。令 `Δ=π/(2K)`；每条角点圆弧相对两个端点间的线性插值在欧氏范数下偏差不超过 `R Δ²/8`，其中 `R≤1+ε/2`。故每段取端点全部角点区间盒的凸包，再加 `L∞` 半径 `ceil(10^12(1+ε/2)π_hi²/(32K²))/10^12`，严格包含整个枢转矩形。完整轴向滑移是首末姿态矩形的凸包，首末角点盒凸包亦外包它。分别将全部多边形关于 `x=0` 镜像；原始半圈末姿态在轴上，反射后逆序运动从该姿态接合，构成连续半转。
4. 所有凸包坐标是整数（单位 `10^-12`）。对每个多边形与每个接触到的闭网格行 `y∈[j/q,(j+1)/q]`，用精确分数求行切片的 x 最小/最大值，列范围为 `ceil(q*x_min)-1` 到 `floor(q*x_max)`（边界同时计入相邻单元）。每行合并整数闭区间，得到整数 `N`；面积的次可加性给出 `≤N/q²`。没有 Shapely、浮点数或容差参与证明路径。闭边界的双计数是有意的保守外包。

本次 q=128 的具体结果：ε=0.05/K16/seed1：`N=8978`，严格上界 `4489/8192≈0.548`；ε=0.002/K256/seed0：`N=6114`，严格上界 `3057/8192≈0.373`。两者都**不能**被误引为先前浮点估计 0.472 / 0.310 已获得认证。当前证书没有求最小网格上界，也没有提供跨 ε 的统一上界。`10^-12` 是外舍入精度而非先验几何误差假设；改变它需要重新生成和验证证书。
