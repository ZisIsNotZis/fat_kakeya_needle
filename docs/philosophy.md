# 项目哲学与目标定义（2026-09-19 定稿）

本文件回答：这个项目追求什么、不追求什么、"成功"如何判定。
与其他文档的关系：findings.md 记录结论，methodology.md 记录教训，
本文件记录**目标与哲学**——当具体实验与目标冲突时，以本文件仲裁。

## 一、目标的两次重定义（演变史）

**v1 目标（天真版）**：数值找到真 minimum f(ε)，从而"验证理论"。
→ 被放弃：数值原则上给不出 minimum；理论 log 律的修正项
（lnln/ln 量级）衰减太慢，在可计算 ε 范围内无法与常数区分。

**v2 目标（undefeatable 版）**：在给定算力下找到"不可击败"的上界
构造——每个 ε 的 best-known 值经得起多 seed、多分辨率、多族攻击，
无任何已知方法能给出更小值。
→ 已达成 ~90%（详见下文证据）。剩余 10% 是跨优化器对比未做。

**v3 目标（当前，可扩展性版）**：不追求"找到了"，追求
"**论证我们能找到**"——即建立 budget → quality 的标度关系，
使读者可以外推：给 N 倍算力，f̂ 会降到哪。同时证明（经验性地）
曲线的**形状**与理论 log 律相符，且我们穷尽了已知方法仍无法
预测"最好在哪里"（每次增加 budget 都能找到更好的，且改进量
波动不稳定）——这本身就是结论。

## 二、v3 的三条工作假说（证据等级不同）

1. **有限区间形状假说**：已报告的数值点可用 A/(ln(1/ε)+B) 拟合（A≈2.27, B≈1.60）；这一拟合不能证明 ε→0 的理论阶或常数，尤其固定 K 枢转族有正面积下限。局部指数趋势和 ε=0.002 离群仍须统一分辨率与随机种子重新检验。
2. **待验证上界**：任一真实连续运动的精确扫掠面积都是 f(ε) 的上界；当前有限采样 f̂ 值可能漏扫，不能直接充当该上界。现有 `strict_bound.py` / `make_certificates.py` 尚不产生严格证书，问题见 `docs/findings.md` 的 2026-09-28 审查节。
3. **预算关系待测**：早期实验中好盆地命中率约 30–50%、seed 间差异可达 46%，但尚未在固定核时预算的网格上测量 budget→quality 曲线。因此目前不能估计无限算力下搜索结果的极限，也不能断言不存在稳定标度律。

## 三、方法论哲学

- **估计量定义**：f̂(ε) = min over N fresh seeds（N≥3），
  永不使用单 seed 值；报告必须附 hit-rate。
- **分辨率匹配**：目标函数采样密度必须与 ε 挂钩
  （n_arc ≥ C/ε 或经验等效），且所有存储值必须带
  评估分辨率元数据。低分辨率目标函数会制造假低值
  （ε=0.005 处曾漏扫 21%）——已造成一次结论反转。
- **跨族攻击**：任何"族内 undefeatable"结论必须经至少两个
  独立运动族复核；族间缺口 >3% 即视为未收敛信号。
- **结论可撤回性**：所有阶段性结论在 morning_report.md 保留
  原文并标注被何证据推翻。两次反转（0.2917 假突破、1.56 假常数）
  均为"低分辨率评估器 artifact"——同一根因。
- **诚实边界**：明确区分"数值估计 / 经验上界 / 严格定理"三层，
  向用户报告时永远标注当前处于哪层。

## 四、剩余工作（按性价比）

1. （高）严格上界证书：给 smooth 族头条解签发（strict_bound.py 就绪），
   把 0.3424@0.005 等数字变成"数学成立的 f 上界"。
2. （高）ε=0.002 的 +16% 偏离裁决：v2 族高分辨率交叉验证。
3. （中）budget-scaling 实验：同一 ε 用 {1, 2, 4, 8}× budget 跑，
   实测 f̂(budget) 曲线——直接回答"无限算力能到哪"（v3 目标的核心
   实验，尚未做）。
4. （低）追更小 ε：算力需求超线性，边际收益递减，暂缓。

## 五、终局判定

当以下三条同时成立时，项目进入维护态（不再主动投入）：
- 曲线在 [ε_min, 0.8] 全程有符合统一评估分辨率与 ≥3 fresh seeds 的可复现值（尚需补齐）；
- 头条数字带经审查的严格上界证书（待做 #1）；
- budget→quality 标度关系有同等核时预算下的实测数据（待做 #3）。

此后新 ε 点或新族的探索仅在有人质疑现有上界时启动。
