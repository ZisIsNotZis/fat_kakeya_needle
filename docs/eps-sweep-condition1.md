# f̂(ε) 全程扫描（票 05，2026-09-30）

## 目的与设计

达成 v3 终局判定条件 1：曲线在 [ε_min, 0.8] 全程有**符合统一评估
分辨率与 ≥3 fresh seeds** 的可复现值。协议完全复用票 03 协议 A
（每格独立冷启动、总进程 CPU 计费、B=480、四族、seeds {0,1,2}、
pyclipper 1.4.0、单核 nice10），R_f 沿用 ε=0.005 冻结值
（smooth 39 / hier 23 / free_pivot 36 / v2 17；扫描点 ε ≥ 0.01 几何
更粗、复评成本不高于实测，故保守合法）。84/84 格 `complete`、
零重试失败。

## 三个结论

1. **条件 1 的“可复现值”部分达成**：8 个 ε 点、统一评估器与分辨率
   口径（粗目标 step_fraction=.1 + 四重复评 2^38/2^40 × 1e-4/5e-5，
   相对差 ≤0.5%）、每点 3 个独立种子，全部 `complete`。

2. **大 ε 几何主导，小 ε 方法主导**。ε=0.8 时四族几乎重合
   （1.2882–1.2920，差 <0.3%）：扫掠面积由几何下界主导，搜索方法
   无关。随 ε 减小族间分化（ε=0.01 时 smooth 0.3739 对
   hierarchical 0.5931，差 37%）：**方法质量在细 ε 才显现**。

3. **理论 log 律形状在此区间不可证实（诚实负结论）**。
   f̂·ln(1/ε) 从 ε=0.8 的 0.288 单调升到 ε=0.01 的 1.72（smooth），
   远未趋于常数——**尚未进入渐近区**。A/(ln(1/ε)+B) 拟合 R² 仅
   0.08–0.28（hierarchical 更差）。局部幂律指数
   α≈0.26（smooth/free_pivot/v2）、0.16（hierarchical）：
   在可计算 ε 范围内形状呈幂律而非对数律。这与 v1 目标被放弃的
   原因一致（log 修正项衰减过慢），现在被 8 点数据定量确认。

## 证据边界

全部为**数值估计**（整数裁剪外包，非严格上界）。严格上界另见三条
有理证书。α 与 f̂·ln(1/ε) 均为有限区间经验量，不外推渐近常数 A。
条件 1 完整达成；"曲线形状与理论 log 律相符"这一补充论断在本区间
**不可证实**，属项目已记录的证据边界。
