## 问题与结论范围

`f(ε)` 是所有 1×ε 矩形针在平面连续自由半转运动的扫掠面积下确界，0<ε≤1。角度的连续提升必须跨过长度 π 的区间；不假设角度单调、中心有界于固定区域或运动属于枢转族。

本页量化 `docs/continuous-motion-bridge.md` 的方向矩形重叠下界，**适用于全体合格运动**，并与指定运动的严格上界组成有限 ε 的区间。它是经典重叠/Cauchy–Schwarz 思路的显式化，不声称文献新颖性、最佳下界或锐常数；不依赖优化器或 Keich 上界构造。

对任意整数 n≥2，定义

`g_ε(θ)=min(1, ε/|sin θ|)`，在 θ=0,π 定义 g=1。

则严格有

`f(ε) ≥ nε / [1 + Σ_{k=1}^{n−1} min(1, ε/sin(kπ/n))]`。  **(1)**

取 n→∞ 还得到解析式

`f(ε) ≥ L(ε) := π / {2[arcsin(ε)/ε + log((1+sqrt(1−ε²))/ε)]}`。  **(2)**

ε=1 时 (2) 等于 1；ε→0 时

`L(ε) = π / {2[log(1/ε)+1+log 2+O(ε²)]}`，

故 `liminf_{ε→0} f(ε) log(1/ε) ≥ π/2`。这是一个有效的下界系数，不是已证明的最优渐近常数，也不证明该极限存在。

## 全体运动的证明

把初始方向归零。连续半转必由介值定理经过 `θ_j=jπ/n`（j=0,…,n−1）；**不重复 θ=π**。在任一这样的时刻取完整矩形 T_j，面积均为 ε；全部包含在扫掠集合 B 中。运动可以回摆，选取时刻无需有任何连续选择性质。

对不同方向 i,j：

- `|T_i∩T_j|≤ε`，因为交集包含于任一矩形；
- 两矩形各包含于宽 ε 的无限条带，条带交叠面积为 `ε²/|sin(θ_i−θ_j)|`。

所以交叠面积至多 `ε g_ε(θ_i−θ_j)`；对角项 i=j 也恰为 ε。令 M=Σ_j 1_{T_j}，则

`∫M=nε`，

`∫M²=Σ_{i,j}|T_i∩T_j| ≤ nε Σ_{k=0}^{n−1}g_ε(kπ/n)`。

有序方向对的每个差值恰有 n 对，sin 的周期绝对值使此分组有效；不能再额外乘 2。由支集上的 Cauchy–Schwarz，

`(nε)² ≤ |B| ∫M²`。

整理即 (1)。该式对每一运动成立，因此也对面积下确界成立；没有用“最小运动存在”的假设。

固定 ε 时 g 在 [0,π] 连续（端点邻域恒为1），所以

`(1/n)Σ g(kπ/n) → (1/π)∫_0^π g(θ)dθ`。

设 α=arcsin ε，直接积分得到

`∫_0^π g(θ)dθ = 2α + 2ε log cot(α/2)`，

而 `cot(α/2)=(1+sqrt(1−ε²))/ε`。对 (1) 取极限即 (2)。**有限 n 的下界无需单调趋向 (2)**；有限方向的某个值可能比其极限略强。

## 有理数计算路径

`direction_overlap_lower_bound.py` 计算 (1) 的保守有理版本，当前实现限偶数 n，但定理本身不要求偶数：

1. `trig_grid(n/2)` 严格包围 sin(kπ/n)，复用既有 Machin/Taylor 精确有理三角区间。
2. 若正下端为 `l_k/D`，取整数 `c_k=min(D, ceil(ε D²/l_k))`，保证 `g(kπ/n)≤c_k/D`；非正下端安全取 c_k=D。
3. 用 `sin((n−k)π/n)=sin(kπ/n)`，求 `S=2Σ_{k=1}^{n/2−1}c_k+c_{n/2}`。
4. 输出精确分数 `nεD/(D+S)`；分母向上包围只使下界更保守，不会伪造过强下界。代码路径不求浮点 log/arcsin。

可复算：

```sh
python direction_overlap_lower_bound.py --eps 0.005 --directions 1024
python -m unittest -v test_direction_overlap_lower_bound.py test_rational_pivot_certificate.py
```

有限 n 结果保存于 `results/direction_overlap_lower_bounds_20261112.json`。JSON 的 seconds 仅是运行墙钟观测，不属于证明。

## 与现有上界组成的严格区间

| ε | 有理下界（n） | 下界显示值 | 指定运动有理上界 | 上界显示值 |
|---:|---|---:|---|---:|
| .05 | 800000000000/2387879065909（1024） | .335025342 | 4489/8192 | .547973633 |
| .005 | 2560000000000/11371543232201（1024） | .225123358 | 3006787/8388608 | .358436942 |
| .002 | 4096000000000/20605569194977（4096） | .198781211 | 673359/2097152 | .321082592 |

这些区间约束真实 f(ε)，不是数值估计置信区间；上界来自三条不同的指定连续运动，下界不依赖这些构造。尤其 ε=.005 的严格区间可向外显示为 **[.22512335, .35843695]**，所认证候选的上界约为通用下界的 1.59 倍。差距不能解释为“候选离真最优恰好这么远”：下界可能松，上界仍有覆盖开销，也可能存在更好的运动。

n4096 对 ε=.005 得到 .224704927，略弱于 n1024；这是有限方向求积的正常现象，不是精度失效。没有搜索最优 n，也没有证明上述是此方法最强的下界。解析 L(.005)≈.224673498 仅作公式显示；严格区间使用有理版本而不是未定向舍入的小数。
