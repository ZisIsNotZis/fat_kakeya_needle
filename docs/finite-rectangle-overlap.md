# 有限长矩形的最大交叠与通用下界（2026-11-12）

**当前状态：完整证明、有理实现与主分数均已独立验收。** 审查证据见 `docs/finite-rectangle-overlap-review-2026-11-12.md`。 只讨论全体1×ε矩形针自由连续半转运动的通用下界，0<ε≤1；不优化或重评任何候选运动。

## 1. 为什么可把两矩形中心重合

引理：对关于原点对称的紧凸集 A,B⊂R²，任意平移 x 都满足

`|A∩(B+x)| ≤ |A∩B|`。

证明：令 C=A∩(B+x)，则 -C=A∩(B−x)。若 C 为空或面积零，结论直接成立；否则 C,-C 为非空紧凸集，且由 A、B 的凸性

`(C+(-C))/2 ⊂ A∩B`。

二维 Brunn–Minkowski 不等式给 `|(C+(-C))/2|^(1/2) ≥ (|C|^(1/2)+|-C|^(1/2))/2 = |C|^(1/2)`，故结论成立。这里明确调用标准 Brunn–Minkowski 定理，并未用数值测试代替该定理。矩形显然满足中心对称、紧致与凸性；先整体平移使一个中心为原点即可应用。

## 2. 同心矩形交叠的精确公式

两矩形方向差用对称性归约到 φ∈[0,π/2]，记 `H_ε(φ)` 为它们中心重合时的交叠面积。令 `a=φ/2`、`t=tan a∈[0,1]`。

把坐标旋转到两方向角平分线，使两矩形方向为 ±a。其交集关于两个坐标轴对称。在第一象限 x,y≥0，四组绝对值约束等价于两条最强约束：

`x cos a+y sin a≤1/2`，`x sin a+y cos a≤ε/2`。

原因是其余带负号的线性组合绝对值不超过对应的正号组合。令 `b=1/(2cos a)`，则约束变为

`x+t y≤b`，`t x+y≤εb`。

- 若 t≥ε，第二个三角形完全包含于第一个三角形：在其两个轴顶点上 `x+t y` 的最大值为 `εb/t≤b`（t≤1）。交集第一象限面积为 `ε² b²/(2t)`。
- 若 0≤t<ε 且 t<1，两线在第一象限交于
  `V=b((1−εt)/(1−t²),(ε−t)/(1−t²))`。
  第一象限交集为四边形 `0,(b,0),V,(0,εb)`；鞋带公式直接给出面积，无需假设切角三角形互不重叠。

四倍第一象限面积给

`H_ε(φ) = (1+t²)[2ε−(1+ε²)t]/[2(1−t²)]`，若 `0≤t≤ε,t<1`；

`H_ε(φ) = ε²(1+t²)/(2t) = ε²/sin φ`，若 `ε≤t≤1,t>0`。

在 t=ε<1 两式一致；φ=0取 H=ε。ε<1、φ=π/2时 H=ε²。唯一共同奇点 ε=t=1 直接由重合方形（相差90°）得 H=1，亦为极限。

ε=1 的小角式约去1−t后为 `(1+t²)/(1+t)`，因此在 t=1 连续。矩形交叠不是总随φ单调：正方形在φ=45°较小、到90°又恢复1；不作错误单调假设。

## 3. 全体连续半转运动的下界

对 n 个不重复均匀方向，连续半转的介值定理选出矩形 T_j。令 `M=Σ1_{T_j}`。第1节给任意中心位置下

`|T_i∩T_j| ≤ H_ε(φ_ij)`，

其中方向差按π周期、关于π/2反射归约。故 Cauchy–Schwarz 如已有方向下界证明给出

`f(ε) ≥ nε² / Σ_{k=0}^{n−1} H_ε(kπ/n)`，

H 按上述对称性延拓到[0,π]。它连续；对固定ε取n→∞的Riemann和，无需连续选择方向时刻，得到

`f(ε) ≥ π ε² / ∫_0^π H_ε(φ)dφ`。

这适用于全体合格连续运动，不仅限同心旋转：同心只用来上界任意两条矩形的交叠。

## 4. 精确积分与简洁推论

先设0<ε<1。用 `dφ=2dt/(1+t²)`，并利用H关于π/2对称：

`∫_0^{π/2} H dφ = ∫_0^ε [2ε−(1+ε²)t]/(1−t²) dt + ∫_ε^1 ε²/t dt`

`= [(1+ε)²log(1+ε)+(1−ε)²log(1−ε)]/2 − ε²log ε`。

因此记

`J(ε)=(1+ε)²log(1+ε)+(1−ε)²log(1−ε)−2ε²log ε`，

则 **`f(ε)≥π ε²/J(ε)`**。ε=1 用连续延拓 `0log0=0`，得 J(1)=4log2，下界π/(4log2)。

令前两项之和为G(ε)。有 `G(0)=G'(0)=0`，且

`G''(ε)=6+2log(1−ε²)≤6`，

积分两次得到 `G(ε)≤3ε²`；ε=1 由连续性保留。因此得到简洁的通用下界

**`f(ε) ≥ π/[2log(1/ε)+3]`，0<ε≤1。**

更精确地，

`G(ε)/ε² = 3 − Σ_{m≥1} ε^(2m)/[m(m+1)(2m+1)]`，

故J的归一化分母为 `2log(1/ε)+3−ε²/6−ε⁴/30−…`。这仍只给渐近下界系数π/2，并未证明系数锐、极限存在或与某个上界构造相合。

## 6. 简洁推论的精确有理证书路径（已验收）

`finite_rectangle_lower_bound.py` 不直接计算容易相消的精确J，而认证已证明的较弱推论π/(2log(1/ε)+3)：

- 写 `x=1/ε=2^q y`，q非负整数，1≤y<2，使用有理运算完成范围缩减。
- 对y及2，令z=(y−1)/(y+1)∈[0,1/3]，利用 `log y=2Σ_{k≥0} z^(2k+1)/(2k+1)`。
- 保留N项是下端；余项≤`2z^(2N+1)/[(2N+1)(1−z²)]`，因为所有后续分母≥2N+1且幂次形成几何级数。把log2与logy的上下端按非负q组合，获得logx严格区间。
- 采用原证书的Machin π下端，向下量化为整数P/D；logx上端向上量化为整数Q/D，D=10^12。故输出 `P/(2Q+3D)` 是保守面积下界。N只控制计算区间宽度；即便N较小、界更松，也不会反转保守方向。

默认N=32，项数不随方向网格变化，无须生成数千方向的三角区间。它的速度不意味着无需数学证明：核心依赖第1—4节几何、BM和CS证明。

## 7. 这个两两重叠松弛为什么不值得继续扩方向网格（已独立审查）

这里的H不仅是上包络，而且是中心矩形族的Gram核：若R_θ为以原点为中心的矩形，则

`H(θ−φ)=∫1_{R_θ}(x)1_{R_φ}(x)dx`。

对方向圆R/(πZ)上的任意非负概率测度μ，令 `M_μ(x)=∫1_{R_θ}(x)dμ(θ)`。它的两两交叠能量为

`E_μ=||M_μ||²_(L²)=∬H(θ−φ)dμ(θ)dμ(φ)`。

所有R_θ都在共同有界圆盘内，且0≤M_μ≤1，所以上述积分及L²范数存在。把μ在旋转群上平均，得到均匀Haar概率测度。相应的平均函数是M_μ的空间旋转平均，故由平方范数的凸性/Jensen，

`E_uniform≤E_μ`，且 `E_uniform=J(ε)/π`。

由于质量固定时CS下界为 `ε²/E_μ`，此松弛中任何非均匀方向权重或有限原子方向选择都不能超过解析值 `π ε²/J(ε)`。这**仅限“以每对矩形中心最大交叠上包络+一次CS”这套松弛**，不证明该值是真f，也不限制使用全局几何、不同矩不等式或别的证法。

这不与旧条带cap公式“有限n有时比其积分强”冲突：那个粗上包络不必是本节的Gram核。

因此，若要实质突破这条下界，应改变松弛而非增加方向数或对权重调参。本轮实施简洁推论而不再扩大有限方向枚举，有明确的数学停止理由。
