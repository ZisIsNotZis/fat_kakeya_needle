## 2. BM中心重合最大交叠：证明有效

对关于原点对称的紧凸集A、B，固定平移x，令 `C=A∩(B+x)`。中心对称给出 `−C=A∩(B−x)`。任取p∈C、q∈−C，由凸性 `(p+q)/2∈A`；写p=b₁+x、q=b₂−x，则平均也在B。因此

`(C+(−C))/2 ⊂ A∩B`。

若C为空或面积零，所求结论平凡。否则二维Brunn–Minkowski给出

`|(C+(−C))/2|^(1/2) ≥ (|C|^(1/2)+|−C|^(1/2))/2 = |C|^(1/2)`。

所以 `|C|≤|A∩B|`。矩形满足紧致、凸性及中心对称前提；相对方向固定而平移任意，正好覆盖下界证明所需的交叠上界。**不要求最大交叠唯一，也不要求实际运动中的矩形中心重合。** 这里明确调用标准BM定理；裁剪测试只检查后续公式，不代替BM。

## 3. 同心交叠几何：阈值与端点

设a=φ/2，t=tan a∈[0,1]，cₐ=cos a，`b=1/(2cₐ)`。旋转坐标使两矩形方向为±a。交集关于两坐标轴对称。在第一象限，其余带减号线性组合的绝对值都被对应正号组合支配，故全部约束恰等价于

`x+t y≤b`，`t x+y≤εb`，`x,y≥0`。

### 3.1 t≥ε

由宽度约束形成的三角形，在两轴顶点的 `x+t y` 值分别为 `εb/t` 与 `εbt`。因0<t≤1，前者较大，且t≥ε时不超过b。因此长度约束不再裁切它。四倍其面积得

`Hε(φ)=ε²(1+t²)/(2t)=ε²/sinφ`。

这也独立解释了阈值：两条宽条带交成的平行四边形，沿任一矩形纵轴的最远坐标均为 `ε/(2t)`；恰在t=ε进入长度1的范围。

### 3.2 0≤t<ε

因ε≤1，两个截轴中x轴由长度约束控制、y轴由宽度约束控制。两直线交于

`V=b((1−εt)/(1−t²),(ε−t)/(1−t²))`。

此区间t<1、两个坐标非负。第一象限确为四边形 `0,(b,0),V,(0,εb)`。鞋带公式四倍后给

`Hε(φ)=(1+t²)[2ε−(1+ε²)t]/[2(1−t²)]`。

这个证明无需假设四个切角三角形不重叠，因此避开了原候选论证最容易遗漏的前提。原三角形式

`ε−[(cosφ+εsinφ−1)²+(sinφ+εcosφ−ε)²]/(4sinφ cosφ)`

在其非奇异小角适用域，与上述式子一致，且独立精确裁剪也验证了两者。

### 3.3 边界

- t=0：H=ε，小角公式直接连续适用。
- t=ε<1：两分支共同为 `ε(1+ε²)/2`，没有间隙或跳跃。
- t=1、ε<1：条带分支给H=ε²。
- ε=t=1：两个同心正方形相差90°，H=1。小角分支可约成 `(1+t²)/(1+t)`，极限也为1。
- 不应假设H随φ单调：ε=1在45°交叠较小、到90°又回到1。现有推导不使用此错误单调性。

## 4. 全体运动下界、积分和简化：系数正确

连续半转包含n个不重复方向jπ/n。每个矩形面积为ε，任意一对的面积交叠由BM引理上界为对应H。对占据函数M应用CS，并按有序指标差模n分组，得到

`f(ε) ≥ nε² / Σ(k=0…n−1)Hε(kπ/n)`。

H在[0,π]连续，按方向对称延拓后，对固定ε取Riemann和极限，得

`f(ε)≥π ε²/∫₀^π Hε(φ)dφ`。

各方向时刻无需连续选择；不存在假设最优运动达到下确界的问题。

独立积分：用 `dφ=2dt/(1+t²)`，并将[0,π/2]积分倍增，则

`∫₀^π H dφ = 2∫₀^ε [2ε−(1+ε²)t]/(1−t²)dt + 2∫ε¹ ε²/t dt`

`= (1+ε)²log(1+ε)+(1−ε)²log(1−ε)−2ε²log ε = J(ε)`。

所以π与2的系数均正确。ε=1的连续极限为 `J(1)=4log2`，精确下界为 `π/(4log2)`，不是1。

令G为J的前两项，则 `G(0)=G′(0)=0`，对0<ε<1，

`G″(ε)=6+2log(1−ε²)≤6`。

两次积分给 `G≤3ε²`；ε=1由连续性成立。分母向上替换得到较弱但简洁的正确下界

`f(ε)≥π/[2log(1/ε)+3]`。

ε=1时简洁式为π/3；不能把它与更强的精确J式混为一谈。对ε→0，归一化分母是 `2log(1/ε)+3−ε²/6−…`，仍仅说明liminf系数至少π/2，没有建立极限存在或锐性。

## 6. log证书实现：范围缩减、尾界与舍入

### 6.1 范围缩减

x=1/ε≥1。初始shift取分子/分母bit_length差，得到y=x/2^shift∈(1/2,2)。若y<1则shift减1、y乘2，便有1≤y<2。x≥1保证shift不会成为负数。代码后续y≥2的防御分支也安全。因此

`log x=shift log2+log y`

是精确恒等式，且所有区间系数shift非负，不会颠倒上下端。

### 6.2 正项atanh级数

z=(y−1)/(y+1)∈[0,1/3]。取N项后

`log y = 2Σ(k=0…N−1) z^(2k+1)/(2k+1) + tail`，

`0≤tail≤2z^(2N+1)/[(2N+1)(1−z²)]`。

尾和每个分母均不小于2N+1，再用几何级数即得该上界，代码指数和因子正确。N=32时尾项从z^65开始；z=0精确返回零。

### 6.3 最终有理下端

代码取 `pn=floor(π_low D)`，`ln=ceil(log_high D)`。于是π/D分子向下、正分母向上，

`pn/(2ln+3D) ≤ π/[2log(1/ε)+3] ≤ f(ε)`。

D约去的形式正确，未漏掉D。ε=1时log精确零，下界为π下端/3。

## 8. 有界附注：精确H核下无需继续优化方向网格或权重

管理者提出的停止理由也成立。把方向视为模π的旋转群，令μ为方向概率测度，`Mμ=∫1_Rθ dμ(θ)`。中心矩形交叠是Gram核，故 `Eμ=∬H(θ−φ)dμ(θ)dμ(φ)=||Mμ||₂²`。对Mμ作群旋转平均恰得到均匀方向的占据函数；L²范数平方的凸性给 `Euniform≤Eμ`。亦可直接得到 `Eμ−Euniform=||Mμ−Muniform||₂²≥0`。

均匀能量为J/π，故在这个**精确中心交叠+加权CS**松弛中，最强下界已经是 `ε²/(J/π)`；有限原子方向或非均匀权重不能超过它。这不排除超出该松弛的新几何信息，但足以停止本路线的方向权重/网格搜索。
