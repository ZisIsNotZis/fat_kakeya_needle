# 03 — 有效运动族的同核时预算—质量基准

Status: ready-for-agent
Need-review: yes
Need-test-cases: yes
Blocked by: 02-stable-long-motion-evaluator

## 目标
在明确已实现运动族集合内，以相同 CPU 核时、独立冷启动和共同稳定评分口径测预算→数值质量；把历史 incumbent 的未知发现成本与增量续搜严格分开，不声称覆盖未知方法或数值证明真 minimum。

## 预注册门槛
- 02 评估器过解析/连续性/长距细针回归后，再固定 ε∈{0.005,0.002}、候选族至少 smooth/pivot、v2-repaired、Keich 递推（后者单独作非优化理论基线），随机种子 ≥3、机器并发和优先级、核时检查点 `{60,120,240,480}` 秒。预算若不足进入搜索代，先测目标函数成本再重新设计，不把初始化结果排名。
- 从零搜索与给定旧解续搜分别记账；所有保存参数以相同几何口径复评，报告每档的全部结果、min-over-seeds、hit-rate、包络间隙和 CPU/墙钟。
- 明确“已测方法中的最好”与“所有已知方法”不能未经穷尽而等同。差距 >3% 视为未收敛，不从有限预算点外推无限算力极限。
